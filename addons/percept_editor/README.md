# Percept

Editor visual pequeño para los árboles de comportamiento de Overcharge.
Es solo una herramienta del editor: el juego no depende de `addons/`.

## Uso

1. Activá el plugin en `Project > Project Settings > Plugins`.
2. Abrí el panel inferior `Percept`.
3. Arrastrá clases desde la paleta, conectalas, editá sus exports y guardá el
   árbol en un `.tres` dentro de `resources/ai/trees/`.

Con el juego corriendo en modo debug, el panel muestra en vivo el agente que
usa el árbol abierto.
